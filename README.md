# Podrão.AI

Primeira lanchonete ai-first do Brasil em arquivo único (`index.html`). Cardápio clicável que monta o pedido, combo indicado pela IA, assistente e pedido pronto no zap.

Produção: https://lanchonete-ai-production.up.railway.app

Deploy: Railway, projeto `lanchonete-ai`, serviço ligado ao repo com Dockerfile nginx na porta 8080.

```powershell
python -m http.server 8000
```
